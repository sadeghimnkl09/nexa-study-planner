نِکسا — برنامه‌ریز مطالعه

کار برنامه: برای هر درس چند کتاب اضافه کن، برای هر کتاب موعد (یا تعداد صفحه در روز) تعیین کن؛ نکسا هر روز می‌گوید از کدام صفحه تا کدام صفحه بخوانی.
اگر یک روز عقب بیفتی، سهم روزهای بعد خودکار دوباره محاسبه می‌شود.

نصب: محتویات پوشه را روی هاست HTTPS (GitHub Pages / Netlify) بگذار و در Chrome گزینه Install app را بزن.
اطلاعات فقط روی همان دستگاه ذخیره می‌شود؛ از منوی ⋯ پشتیبان بگیر. داده‌های قبلی (درس‌ها و کتاب‌ها) حفظ می‌شوند.
